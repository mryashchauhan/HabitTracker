# Animations Placeholders

This folder is prepared for the upcoming premium redesign.
The following Lottie JSON animation files should be added here:

- `celebration.json` (Used for completing a habit or hitting a streak)
- `onboarding-hero.json` (Used in the new Onboarding screen)
- `empty-state.json` (Used when no habits are present)
- `loading.json` (Used for any async loading states)
- `achievement.json` (Used for unlocking milestones)
- `morning.json` (Used for the morning dashboard greeting)

Do not rename these references, as the future redesign will expect these exact filenames.
